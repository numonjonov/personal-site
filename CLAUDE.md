# numonjonov.com — портфолио

Личный сайт Pahlavon Numonjonov. Визуальный язык — монохромный чертёж:
гигантский гротеск Archivo Black, линейки с делениями по краям, плёночное
зерно, инверсия листа из светлого в чёрный по скроллу, сцена с частицами.

Чистые HTML, CSS и JS — **без сборки, без npm, без зависимостей**. Движения
тоже написаны руками: ни GSAP, ни Lenis здесь нет и быть не должно.

Публикация — GitHub Pages, домен в `CNAME` (`numonjonov.com`).

## Запуск

```bash
python3 -m http.server 4321
```

Открыть `http://localhost:4321`. Сервер нужен для относительных ссылок между
страницами; главная откроется и по `file://`.

## Версия на статике — не мелочь

Стили и скрипт подключаются как `styles.css?v=20` и `main.js?v=20`.
**Правите любой из этих двух файлов — поднимите число во всех HTML сразу:**

```bash
python3 - <<'EOF'
import pathlib, re
N = 21                                   # новая версия
for p in pathlib.Path('.').rglob('*.html'):
    if {'prototypes','lab'} & set(p.parts): continue
    s = p.read_text()
    p.write_text(re.sub(r'(styles\.css|main\.js)\?v=\d+', r'\1?v=%d' % N, s))
EOF
```

Без этого браузер и GitHub Pages ещё сутки отдают старый файл, и новая разметка
приезжает с прошлыми стилями — страница выглядит развалившейся. Я на этом уже
попался при переходе на текущий дизайн.

## Где что править

Содержимое лежит **прямо в разметке**, а не в массивах данных: статический HTML
лучше индексируется и читается без JS.

| Что менять | Где |
|---|---|
| Имя на первом экране | `index.html`, `h1.giant` — две строки в `<span>`. Меняете текст — перемерьте самое длинное слово и поправьте делитель `8.5` в `.giant` |
| Слова на лучах схемы | массив `SPOKES` в `main.js` — `bold: true` это ремесло, `false` характер (второй слой придуман мной, не факты) |
| Цифры в блоке статистики | `index.html`, секция `#about`, блок `.stats` |
| Список работ | `index.html`, секция `#index`, `<li>` внутри `ul.work` |
| Слова на сцене частиц | атрибут `data-word` у строк списка и у кнопок `#tabs` |
| Стек | `index.html`, секция `#stack`, блоки `.spec-row` |
| Опыт | `index.html`, секция `#experience`, `<li>` внутри `ol.tl` |
| Палитра | `--paper` и `--ink` в начале `styles.css`; инверсию считает `main.js` |
| Цвета инверсии | константы `PAPER_LIGHT / PAPER_DARK / INK_*` в `main.js` |

Добавили страницу — впишите её в `sitemap.xml`.

## Правила

- **Не добавляй сборщик, фреймворк и зависимости.** Отсутствие тулинга — цель.
  Нужна библиотека — положи файл в `vendor/` и подключи тегом.
- **Названия банковских систем (`iABS`, `MyID`, `e-key`) на сайте — можно.**
  Это продукты вендоров и публичный госсервис. Чего на сайте быть не должно:
  серийник токена, CN сертификата и ФИО владельца из `ekey/CLAUDE.md`, а также
  что-либо из папки `tbc` — там реальные выписки и сверка.
- **Цвет только через `--paper` и `--ink`.** Других цветов на сайте нет, включая
  инлайновые SVG в кейсах: там `rgb(var(--ink))` и `rgba(var(--ink), .6)`.
  Захардкодите `#fff` — оно не переживёт инверсию.
- **Матовое стекло только у `#menu`.** Перенесено из v1, где так было сделано
  окно терминала. Непрозрачная подложка объявлена первой, стекло — внутри
  `@supports`: без проверки поддержки пункты меню легли бы прямо на текст
  страницы. На HUD его вешать нельзя — `backdrop-filter` конфликтует с
  `mix-blend-mode: difference`, которым HUD и держится.
- **HUD работает через `mix-blend-mode: difference`** и поэтому набран белым.
  Он читается на любом фоне без плашки. Не меняйте ему цвет на `var(--ink)` —
  сломается поверх гигантских букв.
- **Первый экран состоит из двух блоков по 100vh:** `.hero-stage` с заголовком
  и пустой `.hero-scene`. Схема рисуется на `#spokes`, зафиксированном на весь
  вьюпорт, и видна ровно пока мимо идёт второй блок. Уберёте `.hero-scene` —
  схеме негде будет держаться в кадре, она мелькнёт и пропадёт.
- **Схема гаснет по расстоянию до нижнего края первого экрана**, а не по
  кратности вьюпорта: канвас зафиксирован, и к приходу раздела About он обязан
  быть чистым, иначе лучи лягут поверх текста.
- **Радиус лучей считается от самой длинной подписи**, а не только от размера
  экрана: луч до края увёл бы своё слово за пределы окна.
- **Уже 760px схема переходит в компактный режим** — остаётся только плотный
  слой (семь слов про ремесло) и мельче кегль. Отключать её на телефоне не надо:
  первый экран там и без того самый пустой.
- **Подмена скролла трансформом — только на мыши.** На тачскрине она рвётся:
  браузер прячет адресную строку, высота вьюпорта скачет, инерция пальца
  конфликтует с интерполяцией. Флаг `smooth` в `main.js` это и решает.
- **Ничего не прячем в CSS до старта скрипта.** Класс `js` на `<html>` ставит сам
  `main.js`. Не отработает — страница читается целиком. У наблюдателя появления
  есть страховочный таймер на 2.5 секунды.
- **`prefers-reduced-motion` выключает всю сцену:** скролл, зерно, частицы,
  курсор. Остаётся плоская статичная страница. Проверяйте при правках движения.
- **Контраст.** Основной текст 16:1, абзацы `.lead` 10.4:1, служебный `.dim`
  4.9:1 — всё выше порога 4.5. Класс `.faint` даёт 2.78:1 и годится **только**
  для декора внутри `aria-hidden`. Не вешайте его на читаемый текст.
- Новый кейс = копия любого файла из `work/` + строка в `sitemap.xml` + запись
  в списке работ на главной.

## Спойлер — заглушка вместо текста

Перенесён из v1 (`spoiler.js`): мерцающая россыпь точек на месте того, что ещё
не написано. Раскрывать нечего, под точками ничего не спрятано. Механика лежит
в `main.js` (`buildSpoilers` / `paintSpoiler`) и в `styles.css` (`.spoiler`),
на страницах **не расставлена** — ставится вручную там, где нужно:

```html
<!-- строка: ширина в ch, высота по умолчанию 1em -->
<span class="spoiler" style="--w:20ch" role="img" aria-label="Не заполнено"></span>

<!-- абзац: задайте и высоту -->
<span class="spoiler" style="--w:54ch;--h:3.4em" role="img" aria-label="Не заполнено"></span>
```

Плотность точек и частота пересыпания — `SP_DENSITY` и `SP_FPS` в `main.js`
(0.07 и 22, как в v1). Цвет берётся из `--ink`, поэтому на инверсии точки
светлеют вместе с темой. При `prefers-reduced-motion` рисуется один статичный
кадр без мерцания, без JS остаётся штриховка из CSS — строка не выглядит
оборванной.
