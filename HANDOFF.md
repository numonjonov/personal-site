## Что произошло сегодня

Сайт переделан под терминальный дизайн по референсу `muhammad-ali.uz`
(репозиторий `kmuhammadali/kmuhammadali.github.io`). Референс — React + Vite +
Tailwind + CMS на Cloudflare; у нас по-прежнему чистые HTML/CSS/JS без сборки,
всё переписано своими руками под тот же вид:

- шапка `>_ root@numonjonov_` с пунктами `./home.exe ./about.sys ./skills.jar
  ./contact.sh`, на телефоне — бургер;
- первый экран: окно терминала, где команды печатаются посимвольно
  (`whoami`, `ls -la portfolio/`, `cat mission.txt`, `echo`);
- лента работ вместо блога: семь записей с ASCII-«обложками», каждая ведёт
  на кейс в `work/`;
- три карточки-ссылки с пульсирующей рамкой и маркер `// END OF PAGE`;
- разделы About, Skills, Contact — сетки карточек с номерами `#01…#06`;
- контакт: форма `message.send()` → `mailto:`, окно `terminal.log`,
  список `connection.links`;
- бинарный фон на 5 % прозрачности, кастомный курсор с инерцией и рябью по
  клику, scramble заголовков цветными глифами;
- `resume.html`, `404.html` и все `work/*.html` переведены на тот же стиль,
  резюме при печати становится чёрным по белому;
- `serve.ps1` — локальный сервер для Windows (Python на машине не было).

Старый монохромный «чертёж» (Archivo Black, HUD-рамка, схема на первом экране,
сцена с частицами, инверсия по скроллу) удалён целиком вместе с его правилами.
`lab/` и `prototypes/` остались как архив прошлого дизайна.

Версия ассетов: **`?v=50`**.

## Деплой

Репозиторий `github.com/numonjonov/personal-site`, ветка `main`, GitHub Pages
собирает оттуда. После пуша проверить:

```bash
gh api repos/numonjonov/personal-site/pages/builds/latest
```

Поле `status` должно стать `built`. Затем на живом домене свериться, что
`index.html` отдаёт `main.js?v=50`.
