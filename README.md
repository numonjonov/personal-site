# Личный сайт

Статический сайт без сборки и зависимостей. Основной язык — английский,
в шапке переключатель **EN / RU / UZ** (выбор запоминается в браузере).

## Файлы

| Файл         | Что внутри                                                              |
|--------------|-------------------------------------------------------------------------|
| `index.html` | Структура страницы + английский текст (он же запасной вариант)          |
| `i18n.js`    | Три словаря переводов: `en`, `ru`, `uz`                                 |
| `styles.css` | Оформление. Цвета и шрифты — вверху файла, в блоках `:root` и тёмной темы |
| `script.js`  | Язык, тема, меню, часы, счётчики, анимации, копирование почты            |

## Дизайн

Оформление в духе сайта Nothing: монохром, прямые углы, линии в 1px,
один красный акцент и точечный шрифт для крупных надписей.

Шрифты подключаются из Google Fonts:

- **Doto** — точечный (dot-matrix), для имени, заголовков и цифр;
- **JetBrains Mono** — технические подписи, меню, кнопки (капс с разрядкой);
- **Inter** — обычные абзацы текста.

Разделы: hero с часами и счётчиками, «Обо мне», таймлайн опыта, проекты,
навыки с бегущей строкой, контакты.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Как менять текст

Каждый переводимый элемент помечен атрибутом `data-i18n="ключ"`.
Текст прямо в `index.html` — английская версия. Русский и узбекский лежат
в `i18n.js` под тем же ключом.

Чтобы поменять, например, заголовок «Обо мне»:

1. В `index.html` найти `data-i18n="about.title"` — поправить английский текст.
2. В `i18n.js` поправить `'about.title'` в словарях `ru` и `uz`.

Новый блок текста добавляется так же: повесить `data-i18n="новый.ключ"` на элемент
и добавить этот ключ во все три словаря. Если ключа нет в `ru`/`uz`,
на странице останется английский вариант — сайт не сломается.

Названия языков программирования, инструментов и имя в заголовке не переводятся —
на них атрибута `data-i18n` нет.

## Цвета

Акцентный цвет задаётся переменной `--accent` в трёх местах `styles.css`:
в `:root` (светлая тема) и в двух тёмных блоках. Меняются все три.

Цифры в счётчиках берутся из атрибута `data-count` в `index.html`
(`3`, `12`, `3`) — подписи к ним переводятся ключами `stats.1…stats.3`.

## Публикация на GitHub Pages

1. Создать на GitHub репозиторий с именем `<ваш-логин>.github.io`.
2. Из этой папки:

```bash
git remote add origin https://github.com/<ваш-логин>/<ваш-логин>.github.io.git
```

3. Запушить:

```bash
git push -u origin main
```

4. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io`.
