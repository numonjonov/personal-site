# Личный сайт — терминал

Сайт устроен как командная строка: разделы не листаются, а вызываются командами
(`about`, `projects`, `contact`…). Без сборки и зависимостей — чистые HTML, CSS и JS.

Основной язык — английский, в шапке окна переключатель **EN / RU / UZ**.
Тема светлая/тёмная, выбор языка и темы запоминается в браузере.

## Файлы

| Файл          | Что внутри                                                        |
|---------------|-------------------------------------------------------------------|
| `index.html`  | Каркас окна: заголовок, экран, подсказки, строка ввода, статус     |
| `site.js`     | Данные без перевода: почта, ссылки, теги, даты, номера проектов    |
| `i18n.js`     | Все тексты на трёх языках                                         |
| `terminal.js` | Движок: разбор команд, вывод, история, автодополнение, темы        |
| `bg.js`       | 3D-фон на canvas: коридор из рамок, реагирует на мышь              |
| `cursor.js`   | Свой курсор: каретка терминала и рамка, догоняющая её              |
| `styles.css`  | Оформление. Цвета — вверху файла, в `:root` и двух тёмных блоках   |

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Команды

| Команда        | Что делает                                    |
|----------------|-----------------------------------------------|
| `help`         | список команд                                 |
| `whoami`       | имя и одна строка о себе                      |
| `about`        | подробнее о себе + факты                      |
| `experience`   | опыт (псевдоним: `exp`)                       |
| `projects`     | проекты со ссылками                           |
| `skills`       | навыки                                        |
| `contact`      | почта и соцсети (псевдоним: `mail`)           |
| `open 001`     | открыть первую ссылку проекта                 |
| `lang ru`      | сменить язык: `en`, `ru`, `uz`                |
| `theme dark`   | сменить тему: `light`, `dark`                 |
| `bg on/off`    | включить или выключить 3D-фон                  |
| `cursor on/off`| свой курсор — включить или выключить           |
| `clear`        | очистить экран (псевдоним: `cls`, ctrl+L)     |
| `sudo`         | пасхалка                                      |

Ещё в строке ввода работают **↑ / ↓** (история) и **Tab** (автодополнение).

Отдельная пасхалка — классический Konami-код (↑ ↑ ↓ ↓ ← → ← → B A), срабатывает
в любом месте страницы, не только в строке ввода. Слушатель — в конце
`terminal.js`, сообщение переведено в `i18n.js` под ключом `ui.konami`.

## Как менять содержимое

Данные разделены на две части, чтобы не дублировать ссылки в трёх языках:

- **`site.js`** — то, что одинаково на любом языке: почта, адреса ссылок,
  теги проектов, даты в опыте, номера проектов (`001`, `002`, …).
- **`i18n.js`** — только тексты: заголовки, описания, подписи.

Связь между ними — по порядку. Второй проект в `SITE.projects` описывается
вторым элементом в `projects.items` каждого словаря. Так же с опытом.

### Добавить проект

1. В `site.js` добавить элемент в `SITE.projects` — id, теги, ссылки.
2. В `i18n.js` добавить `{ title, text }` в `projects.items` **во все три словаря**,
   в том же месте по счёту.

### Почта и соцсети

Почта задаётся полем `email` в `site.js`. Если оставить его пустым, строка
`email` в выводе `contact` останется, но вместо адреса будет прочерк.

У соцсетей можно указать `label` — как ссылка выглядит на экране:

```js
{ key: 'telegram', url: 'https://t.me/CustomAnnotation', label: '@CustomAnnotation' }
```

Без `label` показывается сам адрес без `https://`.

### Поменять текст

Найти нужный блок в `i18n.js` и поправить его в `en`, `ru`, `uz`.
Названия команд не переводятся — их набирают одинаково на любом языке.

### Добавить свою команду

В `terminal.js` в объект `COMMANDS` добавить функцию:

```js
music: function () {
  printLine('out', 'сейчас играет: …');
}
```

Чтобы команда появилась среди кнопок-подсказок, добавьте её имя в массив `VISIBLE`.

## 3D-фон

За окном терминала — коридор из рамок, уходящий вглубь экрана. Рамки стоят на
разной глубине, едут на зрителя и по кругу переставляются с ближнего конца на
дальний. Проекция перспективная: дальние рамки мельче, бледнее и сходятся в
точку. Считается в `bg.js` на обычном canvas, без библиотек.

Мышь двигает точку схода: уводите курсор вправо — коридор поворачивается так,
будто заглядываете в него сбоку. Окно тоже наклоняется, на 1.8° и 1.2°: углы
намеренно маленькие, на большем повороте текст в окне мылится. Без мыши коридор
еле заметно покачивается сам.

Что настраивается в `bg.js`:

| Что                | Где                                            |
|--------------------|------------------------------------------------|
| Число рамок        | `var FRAMES = 24`                              |
| Длина коридора     | `var FAR = 8`                                  |
| Размер рамки       | `var HALF = 1.15`                              |
| Скорость движения  | `var SPEED = 0.009`                            |
| Сила перспективы   | `var FOCAL = 2.6` — чем меньше, тем резче      |
| Масштаб сцены      | `scale = Math.max(W, H) * 0.5`                 |
| Наклон окна        | множители `1.8` и `-1.2` в `tiltWindow`        |

Цвета берутся из темы, поэтому фон перекрашивается вместе со светлой и тёмной
темой. Каждая пятая рамка — акцентная, красная.

Состояние фона видно в статусной строке внизу окна (`BG ON` / `BG OFF` / `BG AUTO`).
Это важно: кнопка `BG` в ряду подсказок работает как выключатель и запоминает
выбор в браузере — без индикатора легко выключить фон и потом не понять, куда он
делся. `BG AUTO` означает, что фон включён, но сейчас не рисуется — например,
окно узкое.

### Клавиатура на телефоне

После нажатия кнопки-подсказки курсор возвращается в строку ввода — но только
там, где есть мышь. На сенсорных экранах этого не делается: фокус в поле
поднимал бы экранную клавиатуру при каждом нажатии. За это отвечает `focusInput()`
в `terminal.js`. Печатать на телефоне по-прежнему можно — надо тапнуть саму
строку ввода.

### На телефоне фона нет

На экранах уже 720px фон не рисуется вовсе, а окно терминала занимает весь
экран без прозрачности и наклона. Так задумано: коридора там всё равно не было
видно, а батарею он тратил.

Гироскоп пробовали — управление фоном через наклон телефона — и убрали вместе
с мобильным фоном.

На узких экранах (уже 720px) кнопка `BG` и строка `bg` в статусной панели
не показываются вовсе — там фон и так никогда не рисуется, кнопка была бы
бесполезной.

Когда фон не рисуется:

- команда `bg off` или кнопка `BG` (выбор запоминается);
- ширина экрана меньше 720px;
- вкладка не активна;
- в системе включено «уменьшить движение» — тогда рисуется один статичный кадр
  и окно не наклоняется.

`BG AUTO` в статусной строке означает, что фон включён, но сейчас не рисуется —
например, окно узкое.

## Страница 404

`404.html` в корне репозитория — GitHub Pages подхватывает такой файл
автоматически для любого несуществующего адреса, без настроек. Оформлена
в том же стиле терминала: печатает путь, по которому пришли, как будто это
набранная команда, и отвечает `command not found`. Тема (светлая/тёмная)
переключается той же кнопкой и помнит выбор через тот же `localStorage`,
что и главная страница — но сам файл самостоятельный, без `terminal.js`
и остальных скриптов, чтобы не тянуть лишнее на страницу ошибки.

**Как проверить:**

- **Локально** — открыть файл напрямую: `http://localhost:8000/404.html`.
  Локальный `python3 -m http.server` не умеет автоматически подставлять
  404.html на несуществующий путь (в отличие от GitHub Pages), так что
  локально можно посмотреть только сам файл, не сценарий «попал на битую
  ссылку».
- **По-настоящему** — после деплоя открыть любой несуществующий адрес
  на сайте, например `numonjonov.com/что-угодно` — GitHub Pages сам
  покажет эту страницу.

## Печать команд и вывода

Всё, что появляется на экране, печатается не разом, а постепенно — как в
настоящем терминале:

- **Команда, запущенная кликом** (кнопка-подсказка, язык, тема) сама
  «печатается» посимвольно в новую строку, прежде чем выполниться —
  функция `runTyped` в `terminal.js`. Скорость — 55 мс на символ.
- **Вывод любой команды** — очередь: строки появляются одна за другой
  с паузой 45 мс между ними, а не все сразу. Все `printLine`/`printKV`
  в итоге идут через `print()`, так что это работает одинаково для
  любой команды, включая новые.
- Своя же напечатанная вручную команда (клавиатурой) эхом появляется
  почти без задержки — это первая строка в пустой очереди.
- При системной настройке «уменьшить движение» всё это отключается,
  текст появляется сразу.

## Свой курсор

Вместо системной стрелки — прямоугольная каретка, как в консоли, и рамка,
которая догоняет её с задержкой. Над ссылками и кнопками рамка раскрывается и
краснеет, над текстом каретка становится тонкой чертой, на нажатии рамка
поджимается. Всё в `cursor.js`, оформление — в блоке «СВОЙ КУРСОР» в `styles.css`.

Системная стрелка прячется только когда свой курсор включён: правило
`:root[data-cursor="on"] * { cursor: none }` вешается скриптом. Если JS не
отработает, мышь останется обычной, а не пропадёт совсем.

На сенсорных экранах скрипт не запускается вообще — курсора там нет, прятать
нечего. Команда `cursor` в этом случае отвечает, что курсор недоступен.

## Приглашение терминала

`pahlavon@numonjonov.com` в заголовке окна и в первой строке при запуске — это не почта,
а приглашение вида «пользователь@машина», как в настоящей консоли. Задаётся
в `site.js`:

```js
handle: 'pahlavon@numonjonov.com',
version: 'v1.0',
```

Оттуда оно подставляется и в заголовок окна, и в строку запуска во всех трёх языках.

## Цвета и шрифты

Акцентный красный — переменная `--accent` в трёх местах `styles.css`:
в `:root` (светлая тема) и в двух тёмных блоках. Меняются все три.

Шрифты из Google Fonts: **JetBrains Mono** — весь интерфейс,
**Doto** (точечный) — имя в выводе `whoami`. У Doto нет кириллицы,
поэтому им набрано только имя латиницей.

## Картинка для превью ссылки

`og.png` (1200×630) — то, что видно, когда ссылку кидают в мессенджер или соцсеть.
На ней тот же коридор и имя точечной матрицей.

Рисуется скриптом `og.py`. В системе не оказалось ни Pillow, ни конвертеров SVG,
поэтому PNG собирается вручную: пиксели в буфер, `zlib` для сжатия, заголовки
чанков по спецификации. Шрифт — своя матрица 5×7 прямо в скрипте.

Перерисовать после правок:

```bash
python3 og.py
```

`og:image` и `twitter:image` в `index.html` указывают на полный адрес
`https://numonjonov.com/og.png?v=2` — с версией в конце. Мессенджеры (особенно
Telegram) кэшируют картинку превью по адресу, а не по содержимому: если
перерисуете `og.png` заново, **поднимите цифру версии в обоих тегах**, иначе
старая картинка будет висеть в кэше мессенджеров сколько угодно, даже если
файл на сервере давно другой.

## Версия без JavaScript

В `index.html` есть блок `<noscript>` с теми же данными обычным текстом —
для поисковиков и на случай выключенного JS. Если меняете содержимое сайта,
поправьте и его.

## Публикация на GitHub Pages

1. Создать на GitHub репозиторий с именем `<ваш-логин>.github.io`.
2. Из этой папки:

```bash
git remote add origin https://github.com/<ваш-логин>/<ваш-логин>.github.io.git
```

3. Запушить:

```bash
git push -u origin main
```

4. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io`.
