# Личный сайт — терминал

Сайт устроен как командная строка: разделы не листаются, а вызываются командами
(`about`, `projects`, `contact`…). Без сборки и зависимостей — чистые HTML, CSS и JS.

Основной язык — английский, в шапке окна переключатель **EN / RU / UZ**.
Тема светлая/тёмная, выбор языка и темы запоминается в браузере.

## Файлы

| Файл          | Что внутри                                                        |
|---------------|-------------------------------------------------------------------|
| `index.html`  | Каркас окна: заголовок, экран, подсказки, строка ввода, статус     |
| `site.js`     | Данные без перевода: почта, ссылки, теги, даты, номера проектов    |
| `i18n.js`     | Все тексты на трёх языках                                         |
| `terminal.js` | Движок: разбор команд, вывод, история, автодополнение, темы        |
| `styles.css`  | Оформление. Цвета — вверху файла, в `:root` и двух тёмных блоках   |

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Команды

| Команда        | Что делает                                    |
|----------------|-----------------------------------------------|
| `help`         | список команд                                 |
| `whoami`       | имя и одна строка о себе                      |
| `about`        | подробнее о себе + факты                      |
| `experience`   | опыт (псевдоним: `exp`)                       |
| `projects`     | проекты со ссылками                           |
| `skills`       | навыки                                        |
| `contact`      | почта и соцсети (псевдоним: `mail`)           |
| `open 001`     | открыть первую ссылку проекта                 |
| `lang ru`      | сменить язык: `en`, `ru`, `uz`                |
| `theme dark`   | сменить тему: `light`, `dark`                 |
| `clear`        | очистить экран (псевдоним: `cls`, ctrl+L)     |
| `sudo`         | пасхалка                                      |

Ещё в строке ввода работают **↑ / ↓** (история) и **Tab** (автодополнение).

## Как менять содержимое

Данные разделены на две части, чтобы не дублировать ссылки в трёх языках:

- **`site.js`** — то, что одинаково на любом языке: почта, адреса ссылок,
  теги проектов, даты в опыте, номера проектов (`001`, `002`, …).
- **`i18n.js`** — только тексты: заголовки, описания, подписи.

Связь между ними — по порядку. Второй проект в `SITE.projects` описывается
вторым элементом в `projects.items` каждого словаря. Так же с опытом.

### Добавить проект

1. В `site.js` добавить элемент в `SITE.projects` — id, теги, ссылки.
2. В `i18n.js` добавить `{ title, text }` в `projects.items` **во все три словаря**,
   в том же месте по счёту.

### Поменять текст

Найти нужный блок в `i18n.js` и поправить его в `en`, `ru`, `uz`.
Названия команд не переводятся — их набирают одинаково на любом языке.

### Добавить свою команду

В `terminal.js` в объект `COMMANDS` добавить функцию:

```js
music: function () {
  printLine('out', 'сейчас играет: …');
}
```

Чтобы команда появилась среди кнопок-подсказок, добавьте её имя в массив `VISIBLE`.

## Приглашение терминала

`pahlavon@numon.uz` в заголовке окна и в первой строке при запуске — это не почта,
а приглашение вида «пользователь@машина», как в настоящей консоли. Задаётся
в `site.js`:

```js
handle: 'pahlavon@numon.uz',
version: 'v1.0',
```

Оттуда оно подставляется и в заголовок окна, и в строку запуска во всех трёх языках.

## Цвета и шрифты

Акцентный красный — переменная `--accent` в трёх местах `styles.css`:
в `:root` (светлая тема) и в двух тёмных блоках. Меняются все три.

Шрифты из Google Fonts: **JetBrains Mono** — весь интерфейс,
**Doto** (точечный) — имя в выводе `whoami`. У Doto нет кириллицы,
поэтому им набрано только имя латиницей.

## Версия без JavaScript

В `index.html` есть блок `<noscript>` с теми же данными обычным текстом —
для поисковиков и на случай выключенного JS. Если меняете содержимое сайта,
поправьте и его.

## Публикация на GitHub Pages

1. Создать на GitHub репозиторий с именем `<ваш-логин>.github.io`.
2. Из этой папки:

```bash
git remote add origin https://github.com/<ваш-логин>/<ваш-логин>.github.io.git
```

3. Запушить:

```bash
git push -u origin main
```

4. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io`.

## Чек-лист перед публикацией

- [ ] Заменить заглушки в `i18n.js`: о себе, опыт, проекты, навыки — во всех трёх языках
- [ ] Проставить настоящие ссылки в `site.js` (сейчас там `#` и пустые адреса соцсетей)
- [ ] Обновить блок `<noscript>` в `index.html`
- [ ] Проверить `<title>` и `<meta name="description">` — их видно в поиске
- [ ] Открыть на телефоне, проверить обе темы и три языка

## Папка `prototypes/`

Черновики четырёх каркасов, из которых выбирался нынешний: плитки, боковая
колонка, горизонтальная лента и терминал. На работу сайта не влияют — можно
удалить командой `rm -rf prototypes`, если больше не нужны.
