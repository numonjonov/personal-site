# numonjonov.com — личный сайт

Сайт-терминал: разделы не листаются, а вызываются командами (`about`, `projects`,
`contact`). Чистые HTML, CSS и JS — **без сборки, без зависимостей, без npm**.

## Запуск

Открыть `index.html` в браузере. Ничего собирать не нужно.
Публикация — GitHub Pages, домен в `CNAME` (`numonjonov.com`).

## Файлы

- `index.html` — каркас окна: заголовок, экран, подсказки, строка ввода, статус.
- `terminal.js` — разбор и выполнение команд.
- `site.js` — данные без перевода: почта, ссылки, теги, даты, номера проектов.
- `i18n.js` — переводы EN / RU / UZ. Основной язык английский.
- `styles.css` — оформление, светлая и тёмная темы.
- `bg.js`, `cursor.js`, `spoiler.js` — фон, курсор, спойлеры.
- `og.py` — генератор `og.png` (1200×630) для превью ссылки. Pillow и конвертеров
  SVG в системе нет, поэтому PNG собирается вручную — не заменяй на библиотеку.
- `prototypes/` — черновики, в продакшен не идут.

## Правила

- **Не добавляй сборщик, фреймворк и зависимости.** Отсутствие тулинга здесь — цель.
- Тексты не хардкодим в разметке: переводимое — в `i18n.js`, данные — в `site.js`.
- Выбор языка и темы хранится в браузере; правя эту логику, проверь все три языка.
- Новая команда терминала = обработчик в `terminal.js` + подсказка + строки во всех языках.
