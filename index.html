WORK

uz-status — public uptime monitor

Java 21 · Spring Boot · PostgreSQL · 2026

A status page for the services Uzbekistan runs on — payments, the tax portal, marketplaces, banks. Probes every minute, 90 days of history at flat storage cost, open JSON API.

exchange — currency tracker, zero dependencies

Python 3.11 · standard library only · 2026

Central-bank and exchange-office rates into SQLite. CLI, Telegram bot, charts and threshold alerts share one core — HTTP, the Telegram client and the chart renderer are all hand-written against the standard library.

tgagent — Telegram Business assistant

Java · Gemini → Groq · SQLite · 2026

An assistant on bare Java with a two-provider model fallback chain and local conversation memory. When the first provider is down or rate-limited, the second one answers.

tekstlybot — media worker in 256 MB

Java · ffmpeg · whisper.cpp · 2026

Compression, audio extraction and speech-to-text through a worker queue — all held inside a 256 MB heap on a small VPS.

plusline / keyline — Telegram bots

Python · aiogram 3 · 2026

Two production bots on aiogram 3: subscriptions, payments and admin tooling, deployed with systemd and watched by Prometheus.

downloader — media fetcher bot

Python · yt-dlp · gallery-dl · 2026

Send a link, get the file. yt-dlp and gallery-dl behind one Telegram interface, with size limits, retries and cleanup that keeps the disk from filling.

MyID · e-key — bank integrations

Java 17 · Spring Boot · Oracle · JavaEE · closed source

A service wrapping the state biometric identification provider, and digital-signature support inside a legacy JavaEE application on WebLogic. Work inside a bank — no case study, but happy to talk about it.
